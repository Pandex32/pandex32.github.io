02 // Architecture

How It Works Under the Hood

Reviewing legal contracts manually is slow, prone to oversight, and cost-prohibitive for growing enterprises. As Technical Consultant & AI System Lead for Affirmative Services, I led the technical architecture and backend engineering of a modular WordPress plugin ([legal_ai_analyzer]) that parses raw contracts into structured, actionable legal intelligence.

Processing Pipeline:
PDF Upload or Raw Text → PHP Text Extractor & Sanitizer → AI Engine Prompt Layer → Risk Report • Clause Audit • E-Signed PDF
03 // Delivery

What I Built & Led

  • Multi-Mode Analysis Engine: Full contract scanning, tiered HIGH/MEDIUM/LOW risk scoring with statutory justification, automated missing UK clause detection (e.g. governing law, indemnity caps, dispute resolution, termination notice), key date extraction, and plain-English executive summaries.
  • Contract Drafting & Dual-Party E-Signatures: English-law contract generation engine (Service Agreements, NDAs, Consultancy) paired with a responsive HTML5 dual-party signature pad for digital execution.
  • Server-Side PDF Handling & Sanitization: High-throughput server-side PDF extraction and structured report generation with strict MIME validation and payload sanitization boundaries.
  • Security Controls & Engineering Workflows: Implementation of nonce validation, input hardening against prompt injection, and disciplined Git version control workflows across the technical team.
